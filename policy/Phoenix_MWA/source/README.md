# Phoenix-MWA RoboTwin source subset

Upstream: https://github.com/OpenPhoenix-Team/Phoenix-MWA/tree/post-train
Pinned source: `16bc6e307ee71b3797e03a4f072a69340f078dab`.

This directory retains RoboTwin training/evaluation entry points, configuration, statistics, simulator patches, and the shared WAM implementation. Other benchmark launchers, task configurations, data and weights are omitted. Shared library modules are kept unchanged because the common runtime imports them. See the parent README for XPolicyLab commands and source_manifest.json for copied-file hashes. Original attribution and licenses remain in LICENSE, NOTICE and LICENSES.
